## Agent skills

### Issue tracker

Issues ficam como arquivos markdown locais em `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Rótulos padrão: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`, `done`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: um `GLOSSARY.md` e `docs/adr/` na raiz. See `docs/agents/domain.md`.

### Testes

Escrever ou rodar testes: `docs/agents/testing.md`. Antes de commitar: `pnpm check` (roda no pre-commit).

### Revisão

Revisar código: `CODING_STANDARDS.md`.
